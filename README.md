⌨️ SyntaxRacer (Coding Speed ​​Test)
An interactive web application designed specifically for programmers to measure and improve their code-typing speed (WPM) and accuracy. It is built entirely using core web technologies, without relying on complex libraries.

🚀 Project Features
Real Code Snippets: The test uses actual code statements and commands found in programming languages ​​(JavaScript, SQL, HTML/CSS) rather than standard words.

Instant Performance Metrics: Accurate measurement of Words Per Minute (WPM) and error rates during typing.

Clean, Responsive Interface: A modern design focused on user experience (UI/UX) and ease of use.

High Performance & Lightweight: Built with pure Vanilla JavaScript to ensure speed and a lightweight footprint.

🛠️ Tech Stack
HTML5: Page structure and interface elements.

CSS3: Styling, layout, and interface effects.

Vanilla JavaScript (ES6+): Event handling, timers, and game logic management.

🚀 How to Run Locally
Clone the repository or download it as a ZIP file:

Bash
git clone https://github.com/YOUR-USERNAME/SyntaxRacer.git
Open the project folder in any code editor (e.g., VS Code).

Open the `index.html` file directly in your web browser to try the application immediately.
